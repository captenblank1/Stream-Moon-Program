# 🌙 Stream Moon

**برنامج تفاعل متقدم مع بثوث TikTok LIVE وماينكرافت**  
**إدارة أوامر الهدايا والتفاعلات بسهولة واحترافية**

---

## ✨ المميزات

- 🎁 **أوامر الهدايا**: تفعيل أوامر مخصصة عند استقبال هدايا TikTok.
- 💬 **أوامر التفاعل**: دعم كامل لتفاعلات (لايك، فولو، كومنت، مشاركة).
- 🎵 **تشغيل الصوت والفيديو**: تشغيل ملفات صوتية وفيديوهات فور حدوث التفاعل.
- ⌨️ **اختصارات الكيبورد**: تنفيذ أوامر لوحة المفاتيح في الألعاب مثل Roblox وMinecraft.
- 📺 **شاشات OBS**: روابط مخصصة لعرض الفيديوهات والتراكبات في OBS.
- 🛡️ **التراكبات (Overlays)**: عرض أسماء الداعمين بشكل احترافي.
- 🔄 **التحديث التلقائي**: تحديث البرنامج تلقائياً عند توفر نسخة جديدة.
- 🌐 **يعمل مع TikTok LIVE و Minecraft RCON**.

---
